Research question

What happens if a RAG-based assistant interprets instructions embedded in lower-trust Markdown as if they were trusted instructions, after successive retrieval turns?

This lab models that authority-crossing mistake with three synthetic retrieved documents, including a nested Markdown block containing a benign, fixed instruction marker. It compares an intentionally vulnerable toy interpreter with a guarded interpreter that treats retrieved data as data.

Research scope: This is a deterministic simulation; it does not demonstrate a bypass of a real model or production guardrail, and it does not reproduce actual context-window attention or truncation behavior.

Predict the outcomes

Consider the sequence before expanding each expected result.

Turn 1–2: Benign retrieval — is an instruction promoted?

No. The context contains only policy text and a Markdown table, so the vulnerable toy interpreter returns the normal policy answer.

Turn 3: Nested Markdown — what does the intentionally vulnerable interpreter do?

It promotes a synthetic marker inside the retrieved document into an instruction and emits the fixed canary SIMULATED_POLICY_OVERRIDE. No external action is executed.

Turn 3: How does the guarded interpreter respond?

It treats the marker as untrusted source text and answers the benign policy question: access log retention is 30 days.
